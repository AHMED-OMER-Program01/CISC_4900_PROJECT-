# CISC_4900_PROJECT-
The repository for my old CISC-4900 project for Brooklyn College.

In this repository, you can find the old .exe installer for WINDOWS, timelogs and other proofs of work, and hopefully still, some presentations, I believe- or at least, the files for such. Sorry for the disorganization!

During my second to last semester in Brooklyn College, I completed my 4900 project- my major's project, essentially. During this, I had to map out, propose, and defend a concept, before developing and logging such. Overall, over the course of around 190 hours, I developed an edu-tainment-like program, which covered the basics of cryptography, while allowing the user to encrypt their own text data, up to and including, Quantum-Resistant formats. It was my first time creating a solid .exe that required an installer, and my first foray into cryptography, much less attempting to understand Quantum-Algol!

The project was, admittedly, as much a learning project as it was a lone project, but I didn't regret making it- only my sloppiness, from back then! If you're checking this out- hello! Well-met, and cheers!
